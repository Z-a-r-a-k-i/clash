# Visual references

Pinned screenshots from commercial top-down RTS games used as the calibration anchor for `docs/visual-spec.md`. Each image is a 5/5 reference; M0 placeholders should land at 3-4 across the spec criteria.

## How to add a reference

Drop a PNG into this directory with a clear filename (e.g. `sc2-low-zoom.png`, `bar-mid-zoom.png`). Update the brief below noting which game / zoom level / why it was picked.
